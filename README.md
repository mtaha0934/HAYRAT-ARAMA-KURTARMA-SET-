# Hayrat Afet Eğitim Seti

Hayrat Arama Kurtarma için hazırlanan, Meta Quest tarayıcısında ve bilgisayarda çalışan üç bölümlük deprem eğitim simülatörü.

| Bölüm | İçerik |
|---|---|
| 1. Tehlike Avı | Evi depreme hazırlama |
| 2. Afet Çantası | Süre içinde doğru afet çantasını hazırlama |
| 3. Enkazda Hayatta Kal | Çanta, sarsıntı ve enkaz altında hayatta kalma |

Tüm set tek dosyadır: `index.html`. Ana menüden bölüm seçilir.

Bir bölümü doğrudan açmak için adresin sonuna ekleyin:

- `#oyun=tehlike`
- `#oyun=canta`
- `#oyun=enkaz`

Oyunlar 3B motoru internetten indirir; cihazın internete bağlı olması gerekir.
